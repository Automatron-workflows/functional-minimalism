# Release audit · 14 November 2026

## Product

Functional Minimalism remains the product name. The promise is **Better UI. Fewer retries.** Its purpose is to reduce repeated corrections by putting the design system, functional-minimalism guidance, and relevant accepted decisions into the first brief. Rams remains attributed inspiration; no endorsement or measured savings are claimed.

The original workshop required digging through Design memory to find a brief. It now has a direct **Get screen brief** action, with an inspectable preview, clipboard fallback, and Markdown download. Each example shows its exact starter command. Shareable workshop URLs accept `?flow=discovery`, `?flow=invoice`, or `?flow=project`.

The audit found a portability issue: a brief generated from the workshop's pack referred to `demo/components.mjs`, while setup installs `src/design-system/components.mjs`. Starter exports now match the installed setup exactly for all three examples. Only applicable accepted decisions are exported. They are scoped to the my-app starter; this does not silently save decisions to the local project's memory.

## Engineering

The first Pages workflow failed because Chrome rendered its requested 390px window at 500px. The evidence audit correctly rejected missing mobile coverage. The runner now captures a real 390px iframe viewport and asserts the actual width. The new runner still requires remote execution and visual inspection before the UI can be called verified.

Pull requests now run the same build/check/browser pipeline as main. Deploy remains restricted to main. Branch-specific workflow concurrency prevents an incoming PR from cancelling a main deployment.

## Distribution

Added contribution guidance, a bug-report form, a design-pack proposal form, a pull-request template, a 14-day launch plan, and drafts for a founder post and technical submission. No outreach or promotional post was sent.

The first success criterion is developers finishing a useful experiment and returning with evidence. Stars follow a product that is useful and easy to share. The plan does not imply a guaranteed star count or invented benchmark results.

## Verification and handoff

All 28 local tests pass. Source checks, assembled-script parsing, ZIP integrity, and packaged setup/doctor pass. Browser and public deployment verification remain incomplete. See [the current verification record](VERIFICATION.md) for exact access failures and the remaining push step.
