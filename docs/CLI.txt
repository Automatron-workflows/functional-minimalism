node bin/design-harness.mjs init ./my-app --client both
node bin/design-harness.mjs validate packs/studio/pack.json
node bin/design-harness.mjs tokens packs/studio/pack.json
node bin/design-harness.mjs brief examples/discovery.screen.json --project ./my-app
node bin/design-harness.mjs check --project ./my-app --css ./my-app/src/styles.css
node bin/design-harness.mjs audit screen.json evidence.json --project ./my-app
node bin/design-harness.mjs remember --project ./my-app --scope project --target my-app --rule "..." --reason "..." --accept
node bin/design-harness.mjs pin --project ./my-app
node bin/design-harness.mjs import-tokens tokens.json --pack pack.json --out new-pack.json --source "Figma file URL / export revision"

init preserves existing instructions and refuses conflicting component files.
brief includes accepted, applicable decisions only. Omit --accept to propose a decision.
pin explicitly accepts a reviewed local pack revision. It does not fetch updates.
import-tokens consumes the documented normalized map, not arbitrary Figma JSON.
check covers registry paths/exports and optional lexical CSS rules, not JSX/TS AST analysis.
audit requires every contract state at every viewport and the pinned packDigest.
Source-only checks explicitly report renderedVerification: not-run.
No npm publication, API keys, model calls, or remote services are required.
