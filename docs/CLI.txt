setup templates: discovery, invoice, project. Clients: codex, claude, both.
setup adds the pinned reference system, a project-scoped contract and START_HERE.md.
For an existing system, use init --pack and your own compatible screen contract.
doctor checks local files, not whether an agent loaded them or rendered a screen.
--compact removes repeated framing while preserving task, component rules and scoped decisions.
brief includes accepted, applicable decisions only; regenerate after memory changes.
init preserves existing instructions and refuses conflicting component files.
pin explicitly accepts a reviewed local pack revision. It does not fetch updates.
import-tokens consumes the documented normalized map, not arbitrary Figma JSON.
check covers registry paths/exports and lexical CSS, not JSX/TS AST analysis.
audit requires every contract state at every viewport and the pinned packDigest.
Source-only checks explicitly report renderedVerification: not-run.
inspect-react reads the application package manifest and optional components.json.
connect-react requires prior init; it records context for an already declared stack.
No libraries are installed. Pick one detected UI system when the choice is ambiguous.
Existing connections are never overwritten; review and move one aside before reconnecting.
brief/check detect relevant React declaration/config drift; installed versions are not certified.
surface plans and essentialByState add task-scope and alternate-state information checks.
Legacy bin/design-harness.mjs remains available. No npm package is published.
